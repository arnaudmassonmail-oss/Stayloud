# STAYLOUD v7.18.73 — Défilement horizontal

- Styles / Groupes : les styles restent verticaux, mais les groupes de chaque style sont sur une ligne qui défile horizontalement (cartes de 150 px, indication « ← glisser → »).
- Le menu de style et « Supprimer » quittent les cartes et passent dans la fiche du groupe (ligne « Style … · Supprimer le groupe »). Le bouton de style se met à jour après le changement.
- Fiche d'un groupe : tout reste vertical sauf les albums précédents, qui passent en défilement horizontal (grande pochette, titre, année, « Extraits » et ronds Deezer / Spotify).
- Le lecteur d'extraits des albums précédents s'ouvre sous la rangée, en pleine largeur. Lancer un autre album remplace le lecteur.
