# STAYLOUD 5.1 — moteur concerts simplifié

Le moteur des concerts est volontairement limité à **deux références** :

1. **Bandsintown**
2. **InfoConcert**

Toutes les autres sources de concerts des anciennes versions sont retirées du chemin de compilation : Songkick, MusicBrainz events, Ticketmaster, sites de salles, agendas spécialisés, recherche générique, etc.

## Fonctionnement

- Pour chaque artiste suivi, STAYLOUD résout sa page artiste Bandsintown et sa page artiste InfoConcert.
- Les dates sont lues uniquement depuis ces deux pages.
- Une date est identifiée par `date + ville + salle`.
- Si les deux sites donnent la même date, elle est fusionnée en une seule fiche et les deux références sont conservées dans `evidence_json` / `event_sources`.
- Les variantes de ponctuation sont normalisées (`La Roche sur Yon` = `La Roche-sur-Yon`).
- Si au moins une des deux sources répond, le calendrier de l'artiste est reconstruit uniquement à partir des résultats obtenus.
- Si les deux sources sont momentanément indisponibles, l'ancien calendrier est conservé pour éviter de tout effacer sur une panne réseau.
- Une migration 5.1 supprime une fois les anciens concerts issus des moteurs précédents.

- https://www.infoconcert.com/
