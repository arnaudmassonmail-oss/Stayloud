# V7.18.90 — Historique des partages reçus

- Nouveau bouton « 📩 Partages reçus » dans Agenda › Mes amis.
- Les groupes partagés par un ami (avec son message) restent dans cet historique après la popup « Quoi de neuf ».
- Actions : Voir la fiche, + Ajouter le groupe, 🗑 Supprimer (avec confirmation). La suppression ne concerne que son propre historique.
- La popup « Quoi de neuf » rappelle où retrouver les partages.
- API : `GET /api/shares/received`, `DELETE /api/shares/:id` ; table D1 `share_hidden`.
