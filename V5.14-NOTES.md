# STAYLOUD v5.14

## Résolution automatique des artistes
- Aucun groupe n'a besoin d'être ajouté en dur dans le code.
- Bandsintown est résolu automatiquement par nom via son endpoint artiste, puis par recherche ciblée sur le domaine si nécessaire.
- InfoConcert est résolu automatiquement par recherche ciblée sur son domaine.
- Les URLs résolues sont mémorisées dans la table `artists`.
- Le moteur de concerts reste limité à Bandsintown + InfoConcert.
- MusicBrainz n'est jamais requis pour la collecte des concerts.

## API Bandsintown
L'API est utilisée avec l'app_id déjà configuré dans le moteur. Bandsintown documente la résolution par nom d'artiste et la récupération des événements à venir.
