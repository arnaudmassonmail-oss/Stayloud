# STAYLOUD 5.6 — concert engine

Concert references are restricted to Bandsintown and InfoConcert.

## Fixes
- Bandsintown: public artist page + individual Bandsintown event-page discovery through search-engine indexing when the public page exposes only the first window.
- InfoConcert: robust artist-page parsing plus InfoConcert event-page discovery fallback.
- Generic artist URL resolution through search restricted to the two allowed domains.
- Discovery nearby concerts no longer writes into the tracked-artist calendar.
- Concert cache migration bumped to 5.6.0.
- Stronger normalization/deduplication remains date + city + venue.

The search engine is only used to locate pages on Bandsintown/InfoConcert; no third concert database is parsed or stored.
