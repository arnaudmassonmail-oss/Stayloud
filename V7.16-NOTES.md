# STAYLOUD v7.16

## Recherche de concerts par ville cible
- Une recherche manuelle est strictement indépendante de la position GPS.
- `targetCity` est la seule ville de référence pour le géocodage et le rayon.
- Les sources ciblées restent Bandsintown, Songkick et Concerts-Metal.
- Une recherche manuelle ne peut plus tomber sur les anciens fallbacks Nantes/Cugand ou MusicBrainz.
- Si les sources ciblées échouent, STAYLOUD affiche zéro résultat plutôt que des concerts d’une autre zone.
- Version serveur/package/frontend alignée sur 7.16.0.
