# STAYLOUD v6.5 — Bandsintown Live Photos

## Photo search fix
- Keeps the selected artist identity and Bandsintown artist URL.
- Discovers public Bandsintown event pages through web search when the artist page is JavaScript-rendered and does not expose the live-photo gallery in server HTML.
- Searches Bing Images specifically for `site:bandsintown.com` live-photo results and accepts only results whose source page is Bandsintown.
- Bandsintown live photos are ranked ahead of the generic Bandsintown profile image.
- Existing metal-specialist and fallback image sources remain available after Bandsintown.
- Concerts, music clips, news and other application modules are unchanged.
