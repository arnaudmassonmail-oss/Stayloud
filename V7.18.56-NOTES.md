# STAYLOUD v7.18.56

Nouveau : « Mon agenda ».
- Sur chaque carte de concert (Mes groupes, Près de moi, Une ville, festivals, fiche d'un groupe), un bouton ☆ : « J'y vais », « Intéressé » ou « Retirer de mon agenda ». Bouton vert ✓ pour « J'y vais », étoile jaune pour « Intéressé ».
- Concerts : 4e onglet « Agenda (n) » avec les concerts « J'y vais » puis « Intéressé », triés par date ; les concerts passés disparaissent.
- Un même concert vu depuis plusieurs listes (même date + même salle) n'a qu'un seul statut.
- Enregistré dans le compte (Cloudflare D1, table `user_concerts`) : la liste est la même sur tous les appareils.
