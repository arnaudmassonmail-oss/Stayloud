# STAYLOUD v5.5

Concert engine remains intentionally limited to **Bandsintown + InfoConcert**.

Fixes in 5.5:
- Bandsintown public calendar is now paginated using the site's own `/past-events?startDate=` window mechanism when the official API key is not configured. This walks forward through the upcoming calendar instead of stopping at the first visible window.
- InfoConcert parser now handles flattened Markdown/HTML and parses the stable CITY -> ARTIST -> DATE -> VENUE sequence. This specifically covers `25 September 2026 -> La Roche-Sur-Yon -> Quai M` for Rise Of The Northstar.
- Markdown headings/emphasis/list markers are normalized before parsing.
- Concert cache migration bumped to 5.5.
- No additional concert source is introduced.
