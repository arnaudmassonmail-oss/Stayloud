# V7.19.0 — Radio métal dans STAYLOUD

- L'onglet **Clips** devient **Clips & Radio**, avec un bouton **Clips | Radio**.
- **Radio** :
  - webradios métal de l'annuaire libre **Radio Browser**, rangées par style (Metal, Black, Death, Thrash, Metalcore, Deathcore, Doom/Stoner, Hardcore, Nu Metal, Progressif, Post-Hardcore, Alternative, Punk, Grunge, Rock) dans des rangées qu'on fait glisser (grilles sur ordinateur) ;
  - menu **« Tous les styles »** pour n'afficher qu'un style ;
  - **⭐ Mes favorites** en premier (enregistrées sur le téléphone).
- Seules les radios qui marchent dans l'app sont proposées : vérifiées par Radio Browser, flux sécurisé (https), format MP3/AAC lisible sur iPhone et Android, sans doublons, sans les radios techno « hardcore ». Jusqu'à 20 radios par style, les plus écoutées en premier. Les listes sont gardées 12 h en cache partagé.
- **Lecteur** :
  - **mini-lecteur** en bas qui reste affiché sur toutes les pages (lecture/pause, ✕ pour arrêter) ; un appui ouvre le **grand lecteur** : EN DIRECT, titre en cours, radio précédente/suivante, volume (sauf iPhone : boutons du téléphone), favori, styles, site de la radio ;
  - **titre en cours** lu dans le flux de la radio (métadonnées ICY) par le serveur, toutes les 20 s, seulement pour les radios de la liste ;
  - commandes sur l'**écran verrouillé** et dans le centre de contrôle (Media Session) ;
  - **un seul son à la fois** : la radio se met en pause quand un extrait d'album démarre, et inversement.
- Confidentialité : paragraphe sur la radio ajouté.
- API : `GET /api/radio/stations?style=`, `GET /api/radio/byids`, `GET /api/radio/nowplaying?id=`, `POST /api/radio/click?id=` (signale l'écoute à Radio Browser, comme il le demande).
