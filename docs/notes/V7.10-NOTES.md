# STAYLOUD v7.10

- Recherche d'ajout d'un groupe durcie : si aucun résultat de groupe ne correspond exactement au nom saisi, STAYLOUD n'ajoute plus un faux groupe avec le nom tapé.
- Un message indique désormais que le groupe n'a pas été trouvé et demande de vérifier l'orthographe.
- En cas d'erreur réseau/backend pendant la vérification, aucun groupe n'est ajouté ; un message demande de réessayer.
- Le comportement des groupes trouvés et des homonymes est conservé.
- Les fonctions photo, description, concerts, actualités, albums, extraits et le reste du projet sont conservées.
