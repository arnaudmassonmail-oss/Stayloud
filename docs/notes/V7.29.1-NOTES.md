# V7.29.1 — Diagnostic des sources de concerts

Les quatre sources (Concerts-Metal, Sueur de Metal, Songkick, Bandsintown) sont marquées « en panne » depuis le début de la surveillance. Les concerts affichés autour de Nantes venaient surtout d'une liste de secours figée dans le code, d'où les concerts manquants (par exemple No Matter What au Zinor le 21 novembre).

- **Mon compte › Administration › État des sources** : nouveau bouton « 🔍 Tester les sources maintenant ». Il lit tout de suite une page de chaque source, par le relais (r.jina.ai) et en direct, et affiche pour chaque essai le code HTTP, la taille, le titre de la page et le nombre de concerts lus. On voit ainsi si le relais n'a plus de crédit (402), si le site bloque le serveur (403, page Cloudflare) ou si la présentation du site a changé (0 concert lu).
- La surveillance enregistre maintenant la vraie raison de l'échec (« relais HTTP 402 · direct HTTP 403 ») au lieu de « no rows » ou « aucun concert lu ».
