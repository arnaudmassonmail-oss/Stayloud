# STAYLOUD v7.18.68 — Albums Deezer / Spotify en un appui

- Sur la fiche d'un groupe, les boutons « Deezer ↗ » et « Spotify ↗ » de chaque album mènent maintenant directement à l'album (et plus à une page de recherche). Si l'appli Deezer ou Spotify est installée sur le téléphone, l'album s'y ouvre et il suffit d'appuyer sur lecture, avec son propre compte.
- Lien Deezer : API publique Deezer. Lien Spotify : Odesli (song.link), gratuit et sans clé.
- Chaque lien est cherché une seule fois puis gardé dans Cloudflare D1. Tant qu'un lien n'est pas trouvé, le bouton garde la page de recherche.
- Un lien n'est retenu que si l'album est bien du même groupe.
