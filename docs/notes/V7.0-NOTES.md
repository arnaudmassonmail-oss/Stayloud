# STAYLOUD v7.0 — moteur de recherche photos

## Photo search
- Reworked image discovery for live, studio/promo and album-cover candidates.
- Bandsintown remains the first source when a canonical Bandsintown identity exists.
- Added a general image-search layer using Brave Image Search when `BRAVE_SEARCH_API_KEY` is configured, otherwise DuckDuckGo Images, then Bing Images as fallback.
- Uses search-engine thumbnails for the proposal cards and keeps the original image URL when available.
- Multiple targeted queries are used instead of a single generic query.
- Strongly rejects logos, search-engine artwork and generic placeholders.
- Does not require the artist name to appear literally in every image title; relevance is scored from the query, page title, source and image metadata.
- Keeps 5-at-a-time pagination and excludes already shown images.

## Safety boundary
- Only photo-search code and its API endpoint/version metadata were changed.
- Concerts, music clips, news, albums, database schema and other application modules were not intentionally changed.
