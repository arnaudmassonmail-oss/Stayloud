# STAYLOUD 5.3

## Correction réelle du problème Emmure / Rise Of The Northstar

- Bandsintown est désormais lu d'abord via son API officielle d'artiste, qui renvoie le calendrier upcoming complet sous forme structurée.
- Plus de faux curseur `/past-events?startDate=...` : cette URL n'était pas une méthode fiable pour paginer le calendrier public.
- Si l'API Bandsintown échoue, le moteur retombe sur la page publique Bandsintown et ses pages événement.
- InfoConcert reste la seule seconde source.
- La fusion reste date + ville + salle.
- La migration 5.3 vide une fois l'ancien cache de concerts.

La documentation officielle Bandsintown décrit l'endpoint `/artists/{artistname}/events` et le paramètre `date=upcoming`, et indique que la réponse contient les événements, dates, salles, villes, pays et liens vers les événements.
