# V7.24.0 — Bouton « Billets »

- Sur chaque carte de concert, la flèche ↗ est remplacée par un bouton **🎫 Billets** :
  - **rouge** quand le lien du concert est une billetterie (HelloAsso, Fnac Spectacles, Ticketmaster, Live Nation, See Tickets, Digitick, Weezevent, Billetweb, Yurplan, Shotgun, Dice, Eventbrite, Festik, InfoConcert…) : il ouvre directement la page d'achat ;
  - **gris** sinon : il ouvre un menu « Page du concert » (la source, qui a souvent un bouton billets), « Fnac Spectacles », « Ticketmaster » et « Rechercher les billets » (recherche web avec le groupe, la ville et la date).
- Les liens Fnac Spectacles et Ticketmaster pourront plus tard devenir des liens d'affiliation.
- 1 test de plus.
