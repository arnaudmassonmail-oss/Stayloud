# V7.22.0 — Ajouter à mon calendrier

- **Sur chaque concert**, le menu ☆ propose maintenant :
  - **Ajouter à mon calendrier** : fichier .ics qui ouvre le calendrier du téléphone (iPhone, Android, Outlook…) ;
  - **Google Agenda** : ouvre l'ajout d'événement prérempli.
- Le concert contient le titre, le lieu, la date, et le lien billets/infos s'il existe. Avec une heure, il dure 3 h. Sans heure, c'est un événement « journée entière ».
- **Concerts › Agenda › Synchroniser avec mon calendrier** : tes concerts « J'y vais » et « Intéressé » s'affichent dans le calendrier du téléphone et se mettent à jour tout seuls (abonnement).
  - iPhone, iPad, Mac : abonnement webcal ;
  - Android : ajout à Google Agenda ;
  - Outlook et autres : lien à copier.
  - Le lien est **secret et personnel**, et peut être changé (l'ancien ne marche plus). « ☆ » devant le titre = Intéressé.
- Confidentialité : paragraphe ajouté sur le lien de synchronisation. Le lien est supprimé avec le compte.
- API : `GET /api/calendar/event.ics`, `GET /api/calendar/feed`, `POST /api/calendar/feed/renew`, `GET /cal/<lien>.ics`.
- 5 tests de plus (32 au total).
