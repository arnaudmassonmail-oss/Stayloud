# V7.23.0 — Sorties à venir

- **Actus › Sorties** (nouveau, à côté de « Actualités ») :
  - **À venir** : les albums et EP annoncés par tes groupes pour l'année qui vient, rangés **par mois**, avec la date et un **compte à rebours** (« dans 12 jours ») ;
  - bouton **📅** pour ajouter la sortie à ton calendrier (quand le jour exact est connu) ;
  - **Sorties récentes** : les 4 derniers mois.
  - Un appui sur une sortie ouvre la fiche du groupe.
- Les données viennent de MusicBrainz, avec la même recherche en tâche de fond que les alertes. La première fois, la liste peut se compléter en une minute : elle se rafraîchit toute seule.
- Le dernier onglet choisi (Actualités ou Sorties) est retenu.
- API : `GET /api/releases`. 1 test de plus (33 au total).
