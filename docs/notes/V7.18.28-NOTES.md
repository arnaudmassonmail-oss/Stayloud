# STAYLOUD v7.18.28

- Concerts : les « * » (mise en forme Markdown des pages sources) n'apparaissent plus autour des titres, salles et villes.
- Recherche par ville : diagnostic détaillé quand aucun concert n'est trouvé — pour chaque source, nombre de concerts trouvés, gardés, et la raison d'un échec (délai dépassé, HTTP 403, HTTP 429…, via le relais r.jina.ai ou en direct).
- Une recherche vide n'est plus gardée en mémoire 20 minutes : la recherche suivante réessaie les sources.
- Option : variable d'environnement `JINA_API_KEY` (clé gratuite jina.ai) pour lever la limite de requêtes du relais.
