# V7.18.97 — Clips en rangées + choix du groupe ; Groupes français par style

- **Clips** :
  - chaque style est une rangée qu'on fait défiler horizontalement, comme dans Styles/Groupes (avec « Fais glisser → »). La position de défilement est gardée ;
  - un 2ᵉ menu **« Tous les groupes »** permet de choisir un groupe suivi (liste filtrée par le style choisi, avec recherche). La fiche du groupe propose 4 liens YouTube : Clips officiels, Concerts live, Dernières vidéos, Albums complets.
- **Découvrir › Groupes français** : un 2ᵉ menu permet de choisir le style (Metalcore, Death Metal, Punk…). Le serveur cherche alors les groupes français de ce style (`style=France:Metalcore`).
