# STAYLOUD v5.4

## Correction réelle du moteur concerts

- Sources de référence concerts : uniquement Bandsintown + InfoConcert.
- Le parseur privilégie le rendu texte de la page source pour éviter les shells HTML client-side.
- L’API Bandsintown n’est utilisée que si `BANDSINTOWN_APP_ID` est explicitement configuré ; le placeholder de la documentation n’est plus utilisé.
- Pour Bandsintown, le bouton Actualiser utilise aussi le widget officiel Bandsintown côté navigateur avec l’ID numérique de l’artiste, `data-display-limit="all"` et `data-display-past-dates="false"`. Les événements rendus par le widget sont renvoyés au backend et fusionnés avec InfoConcert.
- Cela permet de récupérer les dates étrangères que la page publique n’affiche pas toutes dans son HTML initial.
- Migration 5.4 : suppression des anciens événements du cache au premier démarrage.
