# STAYLOUD v7.18.20 — fenêtre de choix de groupe, fiche épurée, plus de zoom

- Plus de zoom automatique sur iPhone quand on touche un champ (nom de groupe, ville, recherche) : les champs sont en 16 px, taille en dessous de laquelle Safari zoome. Le bouton OK / Ajouter reste bien en place.
- Radar et Concerts : la liste déroulante des groupes est remplacée par un bouton qui ouvre une fenêtre aux couleurs STAYLOUD (« Choisir un groupe ») avec une recherche par nom, la photo et le style de chaque groupe, et « Tous les groupes » / « Tous mes groupes » en tête. Le bouton affiche le groupe choisi (bord rouge).
- Fiche d'un groupe : nouveau bouton rouge « Actualités du groupe » qui ouvre le Radar filtré sur ce groupe.
- Fiche d'un groupe : retrait des boutons « Image », « Changer la photo », « Importer une photo », « Modifier la description » et « Supprimer le groupe ».
