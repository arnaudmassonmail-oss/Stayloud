# V7.31.1 — Réglages après le premier test de ScraperAPI

Premier test en production : Concerts-Metal passe par ScraperAPI (55 concerts lus autour de Nantes), et Songkick aussi (3 concerts metal). Trois corrections :

- **Sueur de Metal** : la page arrive bien, mais sa liste de concerts est construite par JavaScript, d'où « 0 concert lu ». La page est maintenant lue avec le rendu JavaScript de ScraperAPI. Ce mode coûte 10 crédits au lieu de 1, donc la page n'est relue que toutes les 24 h.
- **Bandsintown** : ses pages de ville refusent ScraperAPI (« Protected », après plus de 30 s). L'app ne tente plus ce relais pour Bandsintown, sauf en mode renforcé (`SCRAPERAPI_PREMIUM=1`), pour ne pas ralentir chaque recherche. Les concerts de tes groupes via l'API Bandsintown ne sont pas concernés.
- **Ticketmaster** : 0 concert autour de Nantes avec le filtre « metal ». Ticketmaster France range le metal sous plusieurs genres (Metal, Hard Rock, Rock / Metalcore…). L'app demande donc tous les concerts de musique (jusqu'à 400) et garde ceux dont le genre ou le sous-genre est metal, hard rock, punk, hardcore, doom, thrash, stoner…
