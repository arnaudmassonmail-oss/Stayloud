# V7.47.0 — Prêt pour l'appli Android (Google Play)

- Manifest : icônes « maskable » (logo réduit au centre, pour l'icône ronde/carrée d'Android) en plus des icônes normales ; raccourcis (appui long sur l'icône) vers Concerts, Actus, Écouter et Groupes (`/?go=…`) ; `start_url` `/?source=app`.
- L'appli ouvre directement la section demandée par un raccourci (après connexion si besoin), puis nettoie l'adresse.
- `/.well-known/assetlinks.json` : relie l'appli Android à staypit.com (plein écran, sans barre d'adresse). Rempli à partir des variables Render `ANDROID_PACKAGE` et `ANDROID_SHA256` (vide tant qu'elles ne sont pas définies).
- Page web `staypit.com/supprimer-compte.html` (exigée par Google Play) : explique ce qui est effacé, puis supprime le compte avec le nom d'utilisateur (ou l'e-mail) et le mot de passe, après confirmation. Liens ajoutés dans la page Confidentialité.
