# STAYLOUD v7.18.82

- Aide › « Mettre STAYLOUD sur l'écran d'accueil » : tuto en 4 étapes, avec deux onglets.
  - iPhone / iPad : Safari › Partager › « Sur l'écran d'accueil » › Ajouter.
  - Android : Chrome › ⋮ › « Installer l'application ».
- L'onglet du téléphone utilisé est choisi automatiquement.
- Sur Android / Chrome, un bouton « Installer maintenant » apparaît quand le navigateur le permet.
- Si STAYLOUD est déjà ouvert depuis l'icône, le menu l'indique (« ✓ Déjà installé »).
