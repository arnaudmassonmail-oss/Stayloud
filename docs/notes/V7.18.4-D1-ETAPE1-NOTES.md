# STAYLOUD v7.18.4 — D1 étape 1

Cette étape déplace la persistance des comptes hors de SQLite local vers Cloudflare D1.

## D1 contient

- comptes utilisateurs (nom, e-mail, mot de passe haché + sel)
- sessions de connexion
- jetons de récupération de mot de passe
- groupes/artistes associés à chaque utilisateur

## SQLite local reste utilisé pour

- actualités
- concerts / festivals
- cache et données du moteur STAYLOUD
- données techniques existantes

Les fonctions de recherche de villes, concerts, festivals, photos, radar, clips et découverte ne sont pas réécrites.

## Configuration Render

Ajouter :

- CLOUDFLARE_ACCOUNT_ID
- CLOUDFLARE_D1_DATABASE_ID
- CLOUDFLARE_API_TOKEN

Le token doit avoir D1 Read et D1 Write.

Pour la récupération par e-mail :

- APP_PUBLIC_URL
- RESEND_API_KEY
- EMAIL_FROM

Le serveur crée automatiquement les tables D1 au démarrage. Le fichier `d1/schema.sql` est fourni comme référence.

## Première mise en service

Ne pas tester la récupération de mot de passe avant d'avoir validé :

1. création d'un compte
2. connexion
3. déconnexion
4. redémarrage/redéploiement
5. séparation de deux comptes
6. conservation des groupes

Ensuite seulement, tester le lien « Mot de passe oublié ? ».
