# V7.37.0 — Partager un clip (WhatsApp, Messenger…)

- Lecteur de clip : bouton « Partager ce clip ». Sur téléphone, il ouvre le menu de partage (WhatsApp, Messenger, SMS…) ; sur ordinateur, il copie le lien.
- Le lien est une page STAYPIT publique : `staypit.com/clip/<id YouTube>`.
  - Dans WhatsApp / Messenger, l'aperçu montre la miniature du clip, son titre et STAYPIT (balises Open Graph).
  - Ouverte, la page lit le clip (même sans compte), avec « 🤘 Découvrir STAYPIT » et « ▶ Voir sur YouTube ».
- Titre et chaîne du clip : service oEmbed gratuit de YouTube (sans clé), gardés une semaine.
