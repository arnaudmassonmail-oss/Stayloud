# V7.20.1 — Solidité

- **Correctif important** : la v7.20.0 avait fait disparaître 3 écrans. « Supprimer mon compte », « Signaler un concert » et « Concerts signalés » (admin) s'ouvraient vides. Ils sont restaurés.
- **Protection contre les essais de mots de passe** :
  - connexion : 8 erreurs en 15 min bloquent ce compte pendant 15 min, et 30 erreurs depuis une même adresse bloquent cette adresse ;
  - suppression de compte : 5 erreurs de mot de passe en 15 min ;
  - créations de compte : 5 par heure et par adresse ;
  - « mot de passe oublié » : 5 demandes par heure et par adresse, 3 par adresse e-mail, sans jamais révéler si un compte existe ;
  - message clair : « Réessaie dans X minutes ».
- **Surveillance des sources de concerts** (Concerts-Metal, Sueur de Metal, Songkick, Bandsintown) :
  - si une source qui fonctionnait ne renvoie plus rien pendant plus de 24 h (au moins 3 lectures d'affilée), l'administrateur reçoit **un** message « Alerte source » dans Messages reçus ;
  - nouvel écran **Mon compte › Administration › État des sources**.
- **Tests automatiques** (`npm test`, 22 tests) :
  - écrans et menus de l'interface ;
  - dédoublonnage et lecture des agendas ;
  - radio, comptes, protection anti-essais, suppression de compte, accès admin.
  - Ils se lancent sur GitHub à chaque pull request.
- **Rangement** : les notes de version sont dans `docs/notes/`, et le README est à jour.
