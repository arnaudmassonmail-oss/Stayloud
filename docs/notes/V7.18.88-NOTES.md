# STAYLOUD v7.18.88 — Plus de doublons entre sources

- Un concert présent à la fois sur Concerts-Metal et sur Sueur de Metal n'apparaît plus qu'une fois. Deux concerts sont considérés comme identiques s'ils ont :
  - le même groupe principal, même avec des mots en plus (« Syndrome 81 Oi! » / « Syndrome 81 ») ;
  - ou, à la même date, au moins un groupe en commun quand l'ordre de l'affiche diffère (« Arthrosis + … + Deceates » / « Deceates + Arthrosis + … ») ;
  - et le même lieu : même salle, ou même ville quand une source ne donne pas la salle. Les tirets ne comptent pas dans le nom de la ville.
- La version gardée est la plus complète : salle, heure, toutes les premières parties.
- Sueur de Metal : les noms reçus en minuscules sont remis en forme (« syndrome 81 » → « Syndrome 81 »).
