# V7.30.1 — Économies de tokens Jina

Les agendas de Concerts-Metal, Sueur de Metal, Songkick et Bandsintown bloquent le serveur Render : ils ne peuvent être lus que par le relais Jina, qui consomme des tokens. Pour que le crédit dure le plus longtemps possible :

- **Le direct d'abord, le relais ensuite** : l'app essaie d'abord de lire la page en direct (gratuit). Le relais Jina n'est utilisé que si cet essai échoue. Avant, les deux partaient en même temps et Jina était payé même quand le direct suffisait.
- **Pages allégées** : Jina renvoie la page sans images, sans menus et sans pied de page. La réponse est plus courte, donc moins chère.
- **Relecture toutes les 12 h** au lieu de 6 h, pour chaque page d'agenda. Les agendas changent peu dans une journée.
- **Une page n'est demandée qu'une fois** : si la même page est demandée deux fois en 12 h (recherche par ville, régions voisines), elle n'est lue qu'une seule fois.

Le bouton « Tester les sources maintenant » utilise encore le relais à chaque appui (4 pages) : à garder pour les vérifications.
