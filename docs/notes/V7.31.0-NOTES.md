# V7.31.0 — Relais ScraperAPI pour les agendas de concerts

Concerts-Metal, Sueur de Metal, Songkick et Bandsintown bloquent le serveur Render (pages de protection Cloudflare). Jina ne fournit plus de clé gratuite : l'app peut maintenant passer par **ScraperAPI**, qui a un forfait gratuit.

- Si la variable `SCRAPERAPI_KEY` est renseignée sur Render, les pages d'agenda bloquées sont lues par ScraperAPI (depuis la France) au lieu de Jina. Sinon, Jina reste utilisé comme avant.
- `SCRAPERAPI_PREMIUM=1` active le mode renforcé de ScraperAPI, plus efficace contre les protections mais plus coûteux en crédits. À n'essayer que si le mode normal ne passe pas.
- Les économies de la v7.30.1 restent valables : direct d'abord, relais seulement en cas d'échec, relecture toutes les 12 h, une seule lecture par page.
- **Tester les sources maintenant** indique quel relais est utilisé (« Relais ScraperAPI (avec clé) »). Le test peut prendre jusqu'à une minute, car ScraperAPI est parfois lent.
