# V7.33.0 — STAYLOUD devient STAYPIT

Le nom « STAY LOUD » est déjà une marque européenne (classe 41, concerts) : l'appli s'appelle désormais **STAYPIT**.

- Bannière et icônes refaites avec les lettres d'origine : « STAY » ne change pas, « PIT » est recomposé à partir des lettres rouges de « LOUD » (même texture grunge).
- Nouveau fichier de bannière : `public/staypit-banner.jpg` / `.png` (l'ancien `stayloud-banner.*` est supprimé).
- Nom affiché partout : titre de l'onglet, écran d'accueil (manifest), présentation, aide, e-mails (mot de passe oublié, contrôle du jour), agenda (.ics), page Confidentialité.
- Instructions d'installation : « Ouvre staypit.com… ».
- Service worker : cache `staypit-v6` (les anciens fichiers sont rechargés).

Volontairement inchangés :
- l'adresse contact@stayloud-radar.online, tant que la redirection e-mail de staypit.com n'est pas en place ;
- le cookie de session et les réglages enregistrés (`stayloud_session`, `stayloud.*`) : personne n'est déconnecté et rien n'est perdu ;
- les identifiants des concerts dans l'agenda abonné (`@stayloud-radar.online`) : pas de doublons dans les calendriers.
