# STAYLOUD v7.18.67 — Partager un groupe à un ami

- Fiche d'un groupe (suivi ou dans Découvrir) : bouton « PARTAGER À UN AMI ». On choisit un ou plusieurs amis et on peut ajouter un petit mot.
- L'ami voit le partage dans la fenêtre « Quoi de neuf » (« Julien te conseille Red Fang »), avec les boutons « Voir » (ouvre la fiche) et « + Ajouter ».
- On ne peut partager qu'avec ses amis acceptés (table D1 `band_shares`, créée automatiquement). Les groupes suivis restent privés : seul le groupe partagé est envoyé.
