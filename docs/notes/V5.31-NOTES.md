# STAYLOUD v5.31 — photos : pagination réelle

Basée directement sur la v5.19/v5.20 qui donnait les meilleures photos live. Le moteur de concerts n'est pas modifié.

- conserve la recherche d'images Bing qui fonctionnait ;
- ajoute une pagination réelle (`first`) pour les séries suivantes ;
- le bouton « 5 autres photos » demande une nouvelle page ;
- toutes les URLs déjà proposées sont envoyées au serveur comme exclusions ;
- le serveur déduplique URL originale et miniature ;
- si une page fournit trop peu de nouvelles images, le moteur avance encore d'une page automatiquement ;
- la sélection reste limitée à 5 propositions par série ;
- même logique pour « Changer la photo ».
