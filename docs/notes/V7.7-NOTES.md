# STAYLOUD v7.7

- Le bouton `IMAGE ↗` de la fiche d'un groupe ouvre désormais directement Google Images avec le nom exact du groupe comme recherche.
- Exemple : pour Spleen, le bouton ouvre une recherche Google Images sur `Spleen`.
- La recherche s'ouvre dans un nouvel onglet.
- Le bouton `CHANGER LA PHOTO` reste disponible pour modifier la photo enregistrée dans STAYLOUD.
- Aucun changement aux concerts, actualités, extraits, albums ou autres fonctions.
