# STAYLOUD v7.18.23 — présentation de l'application

- Présentation animée en 6 étapes, ouverte automatiquement à la première connexion (sur l'appareil) d'un compte qui n'a encore aucun groupe :
  1. Bienvenue (« aucun groupe n'est enregistré », radar animé)
  2. Ajouter ses groupes dans Styles/Groupes (saisie animée, suggestion, bouton Ajouter)
  3. Le Radar (actualités qui défilent)
  4. Les concerts : Mes groupes / Près de moi / Une ville, rayon, badge « Ton groupe »
  5. La fiche du groupe : dernier album, extraits musicaux, actualités du groupe
  6. « À toi de jouer » → bouton « Ajouter mon premier groupe » (ouvre Styles/Groupes, curseur dans le champ)
- Navigation : Suivant / Précédent, glisser du doigt, flèches du clavier, « Passer ».
- Bouton « ? » dans la barre du haut pour revoir la présentation.
- Radar sans groupe : message « Aucun groupe pour l'instant » avec boutons « + Ajouter un groupe » et « Voir la présentation ».
- Animations entièrement en CSS (pas de fichier vidéo), ralenties si l'appareil demande moins d'animations.
