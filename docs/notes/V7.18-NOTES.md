# STAYLOUD v7.18

## Recherche de concerts — étape 1 : ville saisie comme seule cible

Cette version reprend volontairement la recherche manuelle par ville de zéro.

- Quand l'utilisateur saisit une ville, le GPS et les coordonnées de la position actuelle ne participent plus à la recherche manuelle.
- Le navigateur envoie uniquement le nom de la ville à `/api/discover/city-concerts`.
- Bandsintown est interrogé directement avec la ville saisie.
- Songkick et Concerts-Metal.com sont recherchés à partir du nom de la ville via les pages publiques trouvées par recherche web.
- Les résultats sont affichés sans calcul de distance dans cette étape.
- Aucun fallback Cugand/Nantes/position actuelle n'est utilisé pour une recherche manuelle.
- Le but de cette étape est de valider que `Versailles` reste bien `Versailles` du début à la fin de la chaîne.

La géolocalisation et le rayon seront réintroduits dans une étape séparée après validation de cette base.
