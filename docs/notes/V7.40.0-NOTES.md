# V7.40.0 — Bienvenue : styles préférés et premiers groupes

Pour qu'un nouveau compte ne démarre pas vide.

- Juste après l'inscription (et pour tout compte encore sans groupe), une fenêtre « Bienvenue 🤘 » :
  1. choisir **jusqu'à 3 styles** (🇫🇷 Groupes français, Metalcore, Deathcore, Hardcore, Nu Metal, Death, Black, Thrash, Alternative, Post-Hardcore, Progressif, Punk, Grunge, Rock) ;
  2. **une dizaine de groupes** proposés et déjà cochés (10 pour 1 style, 5+5, 4+3+3), avec leurs prochaines dates (« 🎤 en France le 5 déc · Lyon ») — on décoche ce qu'on ne veut pas ;
  3. « Ajouter ces N groupes » (barre de progression), puis la présentation de l'appli.
  « Passer » reste possible ; la fenêtre n'apparaît qu'une fois par compte et par appareil.
- Choix des groupes : pour chaque style, une liste de groupes connus (beaucoup d'infos : Wikipédia, albums, clips) ; ceux qui ont des **concerts annoncés en France** passent devant, puis ceux qui tournent ailleurs (Bandsintown, gardé 12 h).
- Homonymes (« Architects », « Trust »…) : le groupe MusicBrainz qui porte le bon style (ou français pour la liste française) est choisi.
- Arrivée par un lien « Suivre … » : le groupe partagé est ajouté d'abord, puis la fenêtre Bienvenue s'ouvre.
- Routes : `GET /api/onboarding/suggestions`, `GET /api/onboarding/resolve`, `GET /api/onboarding/styles` (connexion requise).
