# V7.18.91 — Signaler un concert (avec validation admin)

- Nouveau : « 🎸 Signaler un concert » dans le menu Aide (?) et en bas des listes de concerts (« Un concert manque ? »).
- Fiche : nom de la soirée, groupes, date, heure, ville, salle, lien, infos. Contrôles : date à venir, ville réelle (géolocalisée), lien http(s), 10 envois max par jour.
- Le membre suit ses signalements (en attente / validé / refusé).
- Administrateur : Aide › « Concerts signalés » (badge du nombre à valider) avec Valider / Refuser (ou Retirer) / Supprimer.
- Un concert validé apparaît dans « Près de moi » et « Une ville » pour tous, dans le rayon choisi, avec l'étiquette « Signalé ». Pas de doublon si une source le liste déjà.
- Correctif : le badge « 0 » du bouton ? ne s'affiche plus.
- API : `POST /api/community-concerts`, `GET /api/community-concerts/mine`, `GET /api/community-concerts/admin`, `POST /api/community-concerts/:id/approve|reject`, `DELETE /api/community-concerts/:id` ; table D1 `community_concerts`.
