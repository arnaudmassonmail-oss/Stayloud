# STAYLOUD v7.9.2

Correction du bouton « MODIFIER LA DESCRIPTION ».

Cause : la description était injectée directement dans un attribut HTML `onclick`. Les guillemets présents dans certaines descriptions pouvaient casser l'attribut et empêcher complètement le clic de fonctionner.

Correction : le bouton transmet uniquement l'identifiant du groupe, puis l'éditeur récupère la description actuelle via le profil API. La sauvegarde utilise toujours PATCH `/api/artists/:id` et remplace la description enregistrée.

La gestion de la photo de v7.9.1 est conservée. Aucun changement volontaire aux concerts, actualités, albums, extraits ou recherche.
