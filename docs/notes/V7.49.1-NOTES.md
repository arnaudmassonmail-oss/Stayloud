# V7.49.1 — Vidéos : bouton visible dans « Mes concerts passés »

- Le bouton 🎥 n'apparaissait pas sur les concerts passés (Concerts › Agenda › Mes concerts passés utilise une carte à part). Ces cartes affichent maintenant, pendant le mois qui suit le concert, un bouton violet bien visible :
  - « 🎥 Poster une vidéo du concert » (tu y es allé, pas encore de vidéo) ;
  - « 🎥 2 vidéos · ajouter la tienne » ;
  - « 🎥 Vidéos du concert » / « 🎥 2 vidéos » (tu étais intéressé).
