# STAYLOUD v7.14.2

- Preserve v7.14 multi-account behaviour.
- Add account e-mail to new registrations.
- Existing accounts can add/update their recovery e-mail from the “Compte” button.
- Add secure password-reset flow with single-use 30-minute token.
- Reset emails are sent through the Resend HTTP API when `APP_PUBLIC_URL`, `RESEND_API_KEY` and `EMAIL_FROM` are configured.
- Reset requests use a generic response to avoid account enumeration.
- Improve “Découvrir” concert/festival discovery with regional Concerts-Metal feeds selected from the user's actual coordinates.
- Keep the Nantes/Pays de la Loire feed so Cugand, Clisson, Nantes and nearby areas continue to work.
- Add Paris/IDF, Bretagne, Lille, Lyon, Bordeaux, Toulouse, Marseille, Montpellier, Strasbourg and Grenoble regional feeds.
- Fetch the nearest regional feeds in parallel, filter to metal-related events, apply the requested radius, remove past dates, and sort chronologically.
- Festival discovery reuses the same regional metal source engine and only falls back to curated data when no regional result is available.
- No changes to menus/icons, tracked-group concerts, photos, news, albums or clips.
