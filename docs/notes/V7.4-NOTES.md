# STAYLOUD v7.4

- Base: v7.1 (fast group add/background refresh).
- When a group is selected from the disambiguation list, STAYLOUD now uses the group's Bandsintown image automatically when available.
- The add flow no longer launches the photo-search step for a newly selected group. It shows the automatically selected Bandsintown photo and the user only confirms “Ajouter le groupe”.
- If no Bandsintown image is available, the group can still be added without a photo; the photo can be changed later from the artist profile.
- Existing photo editor remains available for changing an already-added group's photo.
- No changes to concerts, music excerpts, news, albums, or other unrelated features.
