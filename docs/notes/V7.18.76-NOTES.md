# STAYLOUD v7.18.76 — Extraits retrouvés plus souvent

- Recherche des albums sur Deezer plus souple : les titres sont comparés mot par mot après nettoyage (« - Live Act » / « (Live) », « Deluxe », « Remastered »…), ce qui règle aussi les albums du même nom que le groupe.
- Si la recherche ne trouve rien, STAYLOUD cherche dans la discographie Deezer du groupe lui-même.
- Un album d'un autre artiste au même titre (groupe hommage…) n'est utilisé qu'en dernier recours pour les extraits, et jamais pour les liens Deezer / Spotify.
- Bouton « Réessayer » sur le message « Extrait indisponible ».
- Appels à Deezer un peu plus espacés (180 ms) pour rester sous sa limite.
