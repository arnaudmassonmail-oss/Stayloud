# V7.35.0 — Tri par distance dans « Mes groupes »

- Concerts › Mes groupes : « Trier : date · distance » à côté de « distances depuis … ».
- Distance : les concerts les plus proches d'abord (à distance égale, le plus tôt d'abord) ; ceux dont la ville n'est pas encore localisée vont à la fin.
- Le choix est gardé sur l'appareil. Sans point de départ, la liste reste triée par date.
