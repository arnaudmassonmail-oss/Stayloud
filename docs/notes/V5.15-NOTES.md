# STAYLOUD v5.15 — lineup / first-part discovery

Cette version conserve Bandsintown + InfoConcert comme calendriers principaux et ajoute une voie générique de découverte des participations :

- recherche de pages d’événements mentionnant explicitement l’artiste comme première partie, support, opening act, guest ou élément de line-up ;
- lecture de la page réelle trouvée, pas du snippet du moteur de recherche ;
- priorité aux données JSON-LD `Event` quand elles existent ;
- déduplication avec les concerts déjà trouvés par Bandsintown/InfoConcert ;
- aucun groupe n’est ajouté dans une liste spéciale : le mécanisme s’applique à n’importe quel artiste.

Exemple visé : un événement Papa Roach peut être enregistré pour LANDMVRKS même si la fiche calendrier LANDMVRKS ne publie pas cette date.

La version du moteur est `5.15.0`; la migration vide une seule fois les anciens événements afin d’éviter les restes des moteurs précédents.
