# STAYLOUD v7.18.81 — Menu Aide et messages

- Le bouton « ? » ouvre le menu Aide :
  - Revoir la présentation ;
  - Nous écrire : formulaire avec sujet (Question, Bug, Idée, Autre) et message ;
  - Mes messages : ses messages et les réponses reçues ;
  - Messages reçus : réservé à l'administrateur, pour lire, répondre ou supprimer.
- Une pastille rouge sur « ? » signale une nouvelle réponse, ou un nouveau message pour l'administrateur.
- Aucune adresse mail nécessaire : tout reste dans l'appli (table D1 `support_messages`, créée automatiquement).
- Administrateur : le tout premier compte créé, ou les noms d'utilisateur listés dans la variable Render `ADMIN_USERS` (séparés par des virgules).
- Anti-abus : 5 messages par heure et par compte au maximum.
