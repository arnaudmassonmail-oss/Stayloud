# V7.43.2 — Raison des échecs d’envoi d’e-mail dans les logs

- « Mot de passe oublié » et alertes du contrôle du jour : quand Resend refuse un envoi, la raison qu’il donne (domaine non vérifié, clé API limitée à un autre domaine, format de `EMAIL_FROM`…) est écrite dans les logs du serveur (Render › Logs), avec l’adresse d’expédition utilisée.
