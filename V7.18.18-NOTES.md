# STAYLOUD v7.18.18 — tous les concerts dans le menu Concerts

- Menu Concerts avec 3 onglets :
  - **Mes groupes** : « Tous mes groupes » ou un groupe, bouton ↻ pour actualiser ; concerts en France, badge « Première partie ».
  - **Près de moi** : « Autour de <ville> (position actuelle) », rayon 10 / 20 / 50 / 100 km, tous les concerts métal avec distance, badge vert « Ton groupe », puis les festivals.
  - **Une ville** : champ ville + OK, même rayon, même liste.
- Toutes les listes ont le même style que les actualités : date, photo (ou initiale), nom du groupe en rouge, salle · ville · distance, pastille rouge pour ouvrir.
- L'onglet, le rayon et la dernière ville sont mémorisés sur l'appareil.
- Découvrir ne garde que la découverte de nouveaux groupes par style (plus de recherche de concerts ni de géolocalisation à l'ouverture).
