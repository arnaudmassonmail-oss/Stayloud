# STAYLOUD v7.15 — moteur de localisation par ville refondu

- Une recherche manuelle utilise désormais un `targetCity` explicite côté serveur.
- Le serveur géocode obligatoirement la ville saisie et ignore les coordonnées GPS lorsqu’une ville est demandée.
- Une ville manuelle non géocodable provoque une erreur claire au lieu de retomber silencieusement sur la position actuelle.
- Ajout d’un endpoint `/api/discover/resolve-city` pour séparer résolution de ville et géolocalisation automatique.
- Géocodage France renforcé : recherche exacte de commune via GeoPlateforme/BAN, puis API Adresse, puis Nominatim.
- Songkick Metal : nouveau parseur adapté à la structure actuelle des pages (titre → salle/ville → date).
- Bandsintown Metal : parseur de secours pour les variantes actuelles de rendu des agendas de ville.
- Le principe des 3 sources reste : Bandsintown + Songkick + Concerts-Metal.com, avec filtrage géographique final autour de la ville cible.
- Le bouton « Utiliser ma position » reste indépendant.
- Aucun autre module fonctionnel de STAYLOUD n’est modifié.
